============================================================
一、感知（Perception）
============================================================

1.1 激光雷达与点云基础
- Livox MID-360 固态雷达特性（非重复扫描、CustomMsg、内置 IMU）
- 点云坐标系：雷达坐标系 / camera_init / body / base_link
- 双雷达时间同步与外参标定
- 点云融合：时间窗对齐 + 刚体变换融合

1.2 LiDAR-Inertial Odometry（LIO）
- IMU 运动模型与噪声模型
- IMU 传播（propagation）与状态预测
- 点云去畸变（deskew / motion compensation）
- 前向-后向运动补偿
- 迭代误差状态卡尔曼滤波（ESIKF / IEKF）
- 卡尔曼增益、状态更新、误差状态
- iVox 体素最近邻搜索
- 点-平面 / 点-线残差
- 状态：[p, v, R, ba, bg] 或对应形式

1.3 Point-LIO 特有
- batch 处理与时间窗
- 盲区（blind）与盲区中心偏移
- cloud_registered_full 完整点云生成链路
- 稠密点云有序队列与异常点剔除
- 高频 odom 与点云降频发布策略


============================================================
二、地图（Mapping）
============================================================

2.1 概率占据地图
- Log-odds 概率更新
- hit / miss / decay 模型
- raycasting（光线投射）更新占据栅格
- 滑动窗口地图（sliding window map）
- 动态障碍遗忘：keep_time / clear_time

2.2 投影与地形语义
- 三维占据 → 二维投影
- FREE / PASSABLE / OCCUPIED / UNKNOWN 分类
- 高度差（height delta）阈值
- 保守先验地图融合

2.3 Signed ESDF
- 欧氏距离场（Euclidean Distance Field）
- Signed Distance Field：障碍外正、障碍内负
- 截断距离（truncation distance）
- ESDF 梯度与梯度恢复（gradient-based recovery）
- 最近障碍查询


============================================================
三、规划（Planning）
============================================================

3.1 路径搜索
- A* / Dijkstra
- SMAC（State Lattice A* / Hybrid-A*）
- Theta* / 视线检查（line-of-sight）
- 代价地图（costmap）与势场
- 启发函数设计

3.2 轨迹表示
- B-spline / 均匀 B 样条
- 控制点（control points）与节点向量
- MINCO：Minimum Control Effort 轨迹
- 段时间（time allocation）
- 多项式样条与连续性

3.3 轨迹优化
- 软约束优化：位置安全、速度、加速度、加加速度
- ESDF 位置代价
- 前端路径吸引项
- 硬约束校验（discrete validation）
- 热启动（warm start）
- 时间优化（time optimization）

3.4 规划状态机（FSM）
- 初始化 / 待命 / 规划 / 跟踪 / 急停 / 恢复
- replan 触发条件
- 旧轨迹复用与覆盖策略
- 安全距离与碰撞阈值


============================================================
四、控制（Control）
============================================================

4.1 模型预测控制（MPC）
- MPC 基本框架：预测模型 + 代价函数 + 约束 + 滚动优化
- 离散化模型
- 预测时域与控制时域
- 参考轨迹跟踪

4.2 SE(2) 模型
- 状态：[x, y, yaw]
- 控制：[vx, vy, omega]
- 世界坐标系速度 vs 车体坐标系速度
- 全向底盘运动学

4.3 QP 求解
- 二次规划（Quadratic Programming）
- qpOASES 求解器
- 凝聚法（condensing）
- 速度/加速度约束
- 控制延迟补偿
- 杆臂补偿（lidar offset compensation）

============================================================
八、学习优先级建议
============================================================

按"先能看懂数据流，再补算法"的顺序：

1. ROS 2 通信与 QoS（已会，快速过）
2. 坐标系与 TF / 外参
3. 点云去畸变与 LIO 框架
4. 占据栅格与 ESDF
5. A* / SMAC 路径搜索
6. MINCO 轨迹优化思想
7. SE(2) MPC
8. Behavior Tree

其中 LIO、ESDF、MINCO、MPC 是这份代码的四个核心算法硬骨头，建议每个都单独花时间。

9.1 书籍
------
- 《自动驾驶与机器人中的 SLAM 技术》高翔
  作用：LIO、点云处理、状态估计入门最推荐的中文书。

- 《视觉 SLAM 十四讲：从理论到实践》高翔
  作用：补李群李代数、BA、非线性优化基础。

- 《Planning Algorithms》Steven M. LaValle
  作用：路径规划、搜索算法、运动规划经典教材，网上有免费电子版。

- 《Numerical Optimization》Jorge Nocedal, Stephen Wright
  作用：理解优化问题、约束、KKT、梯度下降/牛顿法/内点法。

- 《Underactuated Robotics》Russ Tedrake（MIT，网上免费）
  作用：MPC、最优控制、机器人动力学。
